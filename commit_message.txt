🧪 Add unit tests for PlaybackSpeedDial component

🎯 **What:** The testing gap addressed
Added a comprehensive suite of unit tests for the `PlaybackSpeedDial` component which previously had no test coverage.

📊 **Coverage:** What scenarios are now tested
- Validates the component renders `null` correctly when `open=false`.
- Validates standard rendering of speed labels and slider element when `open=true`.
- Ensures backdrop click and escape key events correctly call `onOpenChange(false)`.
- Simulates clicking a specific speed option label and verifying both `onValueChange` and `onOpenChange`.
- Mocks and simulates keydown interactions (`ArrowRight`, `ArrowLeft`, `Home`, `End`) explicitly verifying index bounds on speeds.
- Simulates advanced track drag events via pointer inputs (`pointerDown`, `pointerMove`, `pointerUp`) by calculating virtual slider state changes correctly.

✨ **Result:** The improvement in test coverage
Eliminated a coverage gap by introducing 7 full component functional unit tests to `PlaybackSpeedDial.test.tsx`, improving overall resilience during UI refactors.
